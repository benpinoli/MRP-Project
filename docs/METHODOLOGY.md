**frequency**: Daily observed dates; Asia/Seoul local dates. Exact close timestamp absent; same venue/date alignment, not verified synchronized ticks.

**calendar**: Session proxy: union of dates with at least one eligible local quote. Missing pairs retained on this grid. Both-carried/absent-both dates are not assumed sessions. Independent KRX calendar unavailable. Full vendor union dates and absent-both weekdays used to break plotted lines.

**sample**: Full available 2005-2026 sample; raw-price panels since 2019-01-01. Main retains eligible flagged observations; sensitivity masks all flagged dates before summary, differences and rolling calculations, without dropping grid rows. No price or volume fill.

**eligibility**: Exact identity/currency/exchange/type mapping; finite positive PRCCD; QUNIT=1; PRCSTD=10; weekday; reject available inconsistent high/low. Volume is not an eligibility gate. Unknown statuses excluded. Missing either class excludes date; duplicate keys or descriptor mismatches abort.

**carried_and_stale**: Vendor status 5 is carried forward and excluded even if volume exists. Status 10 may have missing volume when price changes. Unchanged traded closes retained, not automatically stale. Missing/nonpositive volume separately flagged, never filled.

**corporate_actions**: Raw-price discount only; contemporaneous QUNIT=1 verified. AJEXDI and split events inventoried without adopting an adjustment formula. All adjusted prices, indexes and returns deferred. No TRFD or dividend adjustment used.

**availability**: Effective observation date=datadate; availability/publication/retrieval dates and vendor revision vintage unknown. Filesystem dates are not retrieval evidence. Descriptive retrospective study only.

**windows**: Adjacent observed-session discount differences. Trailing 20 session-endpoint changes, sample standard deviation ddof=1, minimum 20 finite changes, no annualization. Thus requires 21 valid consecutive price observations. No lookahead or centered window. Yearly equal-observation boxplots; 2026 partial through input end.

**validation**: unittest synthetic arithmetic/split/join/filter fixtures; complete-key and finite-value checks; registry JSON Schema; Markdown parity; raw SHA-256 before/after; issuer ISIN/split cross-check; additional independent historical price and calendar reconciliation still pending

**limitations**: ["Observed gap is not identified vote value", "Adjustment formula unresolved; split-adjusted panel deferred", "Independent session calendar and quote reconciliation incomplete", "Vendor exchange/type code tables and export metadata incomplete", "Full historical rights/action audit incomplete", "No return, factor-regression or trade-feasibility inference"]

### quality_audit Coverage and discontinuity diagnostics

**id**: quality_audit

**name**: Coverage and discontinuity diagnostics

**version**: 2.0.0

**status**: implemented

**author**: Codex

**hypothesis_ids**: ["H0"]

**formula**: Raw-row and unique-date counts as labeled; missing=blank. Duplicate excess=N-N_unique(gvkey,iid,datadate). Paired coverage=N_valid/N_union. Equal-observation median. Review flags: absolute adjacent matched-date discount change >5pp or gap >10 calendar days; flags never remove values. Factor changes inventoried only; adjusted returns not computed. Old/new raw rows compared field-by-field by gvkey/iid/date; revised fields and missing keys reported.

**symbols**: N=row/date count as labeled; observed-date changes can span sessions; thresholds from config

**implementation_ref**: src/samsung_research/e01.py:audit

**example**: Three rows with two unique keys give one duplicate excess; a missing common row prevents a pair even if preferred trades.

**limitations**: ["Missing business weekdays are not identified missing trading sessions without KRX calendar", "Large moves are review flags, not automatically data errors"]
