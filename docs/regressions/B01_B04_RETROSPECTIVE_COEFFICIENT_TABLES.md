## Glossary

| Label | Definition |
|---|---|
| B01 | Daily discount change (`dd_pp`) on the aligned US factor-return block. |
| B02 | Daily log-gap change (`dg`) on the aligned US factor-return block. |
| B03 | B01 plus the prior-session discount. |
| B04 | B03 plus prior-session log preferred/common trading activity. These are specification identifiers, not acronyms. |
| `dd_pp` | Daily change in `100 × (1 − preferred price/common price)`, measured in percentage points. |
| `dg` | Daily change in `log(common price/preferred price)`; dimensionless. |
| `F_` | Prefix marking a factor return aligned to the Korean session under the retrospective preceding-US-session rule. |
| USSLOWL | Exact source model-family code used by the school data pipeline. Accessible documentation identifies it as US, but does not provide a verified expansion of every character, so none is inferred here. |
| COUNTRY | Vendor country factor. It must not automatically be interpreted as a conventional market return. |
| BETA | Vendor beta style factor. |
| VALUE | Vendor value style factor. |
| SIZE | Vendor size style factor. |
| MOMENTUM | Vendor momentum style factor. |
| LIQUIDTY | Vendor field spelling for the liquidity style factor. |
| RESVOL | Residual-volatility style factor. |
| LEVERAGE | Leverage style factor. |
| DIVYILD | Dividend-yield style factor. |
| PROFIT | Profitability style factor. |
| SEMICOND | Semiconductor-industry factor. |
| HAC | Heteroskedasticity-and-autocorrelation-consistent covariance estimator. The central display uses Bartlett/Newey–West bandwidth 20 on the original session grid. |
| SE | Standard error of the estimated coefficient. |
| p | Two-sided asymptotic p-value for a zero-coefficient test. |
| BH q | Benjamini–Hochberg multiplicity-adjusted p-value across successful non-intercept tests in the retrospective submission. |
| n | Number of complete observations used in the regression. |
| R² | Coefficient of determination. Adjusted R² accounts for the number of fitted parameters. |
| Main | EP01 sample retaining review-flagged dates where the paired-price observation remains eligible. |
| Sensitivity | EP01 variant masking the registered flagged dates and affected changes. |
