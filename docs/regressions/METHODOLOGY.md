# RG estimation methodology 1.1.0

## Separately versioned research modes

The original `strict_timestamp` mode is unchanged: it requires reviewed Barra metadata, an independent factor calendar, exact factor period-end/availability timestamps, and Korean close timestamps. `discount_only` runs B00 directly on the hash-validated EP01 observed-session grid and requires none of those factor inputs. `retrospective_us_barra` runs only B01–B04 and converts the documented percent-valued USSLOWL returns to decimals.

The retrospective date rule for Korean session date `t` is explicit: sum US factor rows with source date in `[previous Korean session date, t)`. Thus same-date US information is never used; Friday maps to Korean Monday, multiple US sessions are summed across Korean holidays, and a bin empty because of a US holiday remains missing. The source pipeline preserves the vendor daily-factor-return row date and multiplies raw returns by 100; `sf_quant.load_factors` documents the resulting values as percent returns. Exact publication timestamps and revision history are unavailable. Consequently this alignment is a retrospective explanatory sensitivity only and makes no point-in-time forecasting-validity claim.

## Outcomes and units

For synchronized comparable raw common and preferred prices C and P, d=1-P/C, q=100d and g=log(C/P)=-log(1-d). Primary `dd_pp` = q_t-q_(t-1); positive means widening. Secondary `dg` = g_t-g_(t-1), dimensionless. Example: C=100, P rises from 80 to 82 with common unchanged: discount falls 20%→18%, `dd_pp`=-2 and `dg`=log(80/82). A simultaneous equal split cancels in the price ratio; unequal class actions require an entitlement audit. Neither outcome is a dividend-adjusted return.

Retain each observed session in the existing EP01 grid, including ineligible pairs. Difference and lag BEFORE complete-case filtering. Mask both affected change endpoints when sensitivity removes a date; never difference across a removed date. Dates absent both classes remain a calendar limitation. Long intervals and other review flags remain visible in main and masked in sensitivity. No winsorization, interpolation or zero replacement.

## Model families

Baseline B00: `dd_pp_t = alpha + rho*q_(t-1) + e_t`. B01: `dd_pp_t = alpha + beta'F_t + e_t`. B02 uses `dg_t`. B03 adds lagged q to B01. B04 adds lagged log(preferred/common volume) as an activity control, not an observed trading cost. These nested comparisons must also be refit on a common complete-case sample before incremental fit is interpreted; the initial engine reports native samples and marks this follow-up required.

Mechanism models use `dd_pp_t = alpha + beta'F_t + rho*q_(t-1) + gamma'Z_(t-1) + e_t`. All optional columns are defined in [FACTORS.md](FACTORS.md). J01 includes all named mechanism columns together; X01/X02 add explicitly registered products. A lag establishes ordering under the declared availability rule, not exogeneity. Contemporaneous F is an explanatory control; these models are not forecasts. Coefficients remain in original units; include intercept; solve with least squares, no unannounced selection.

## Barra and residual interpretation

Prefer Korea-model or verified Korea-covered global factors with documented return currency. A US model can measure external state but cannot be labeled Korean specific risk. The shipped API is [load_factors](../../src/sf_quant/data/factors.py); static names are [here](../../src/sf_quant/data/_factors.py). Select a modest core (market, value, size, momentum, liquidity, volatility, leverage, yield, profitability/growth where actually available) plus semiconductor exposure, then a broad-factor sensitivity after rank checks. The default executable config uses shipped US names and therefore requires explicit US-sensitivity acknowledgement in metadata. Replace names after inspecting the actual Korea/global export; never invent a Korean prefix.

For verified class total returns r_j,t, attribution would be `r_j,t=b_j,t-1' f_t + u_j,t`, then `r_C-r_P=(b_C-b_P)'f+(u_C-u_P)`. This vendor-exposure method requires dated exposure identifiers, return conventions and lagged exposures. A time-series fit of `dg` on F instead estimates constant statistical loadings of a relative price change. Its residual is a model-conditional gap innovation, not a vendor specific return. Returns and factor-adjusted price changes also mix cash-flow and required-return news; identifying a discount-rate change needs additional valuation restrictions. The current engine implements the latter gap regressions only.

Use a joint regression to estimate mechanism coefficients conditional on F. If using Frisch–Waugh–Lovell for interpretation, project BOTH y and Z off exactly the same intercept/F matrix on exactly the same rows; residualizing only y is wrong. Retain joint-regression inference. Full-sample residuals must not be used in predictive evaluation; rolling/expanding nuisance fits must be estimated solely on the training past.

## Timing and holidays

Every Korean endpoint has an explicit UTC close from `sessions.csv`. Factor rows have observation date, actual return-period end UTC and availability UTC from `factor_timing.csv`. For the explanatory default, sum arithmetic factor returns whose period END falls in `(previous_Korean_close, current_Korean_close]`, requiring every included row to have been available by the current endpoint. The supplied factor trading calendar must declare every expected observation; absent observations fail preparation. Multiple foreign sessions during a Korean holiday are summed. Empty bins are missing, never zero or carried. The sum is a factor shock proxy, not compounded investable wealth. Source periods may overlap the Korean interval; end-time binning does not establish synchronized attribution. Save every factor date/bin mapping and interval duration.

For US factors this generally associates the US close of the previous US business day with the next Korean endpoint. No `shift(-1)` or blind calendar-day subtraction. For prediction, aggregate only factors available before the forecast origin; that is a separate, unimplemented design. Revisions and public release timing of optional mechanisms must be addressed in their metadata; a modern restatement is retrospective only.

## Collinearity, inference and sample discipline

Barra factors are not guaranteed orthogonal in a time series; country/industry constraints, extra market proxies, interaction terms and duplicated macro series can introduce dependencies. Check variance, singular values, rank, standardized condition number and VIF. Rank deficiency and standardized condition number >1e8 block fitting; report VIF >10 and correlations rather than silently remove columns. Scaling is for diagnostics only. QR/PCA/ridge may support later predictive sensitivities but change coefficient interpretation and require chronological tuning. Twenty years allow many columns algebraically, but persistence, regime changes and repeated slow data limit effective information. Require n>=max(252,20*k), with k including intercept, and report calendar span and n/k.

OLS covariance uses Bartlett Newey–West scores on the ORIGINAL session grid with missing-row scores set to zero; bandwidths 5, 20, 60 sessions, finite-sample multiplier n/(n-k). Grid holes are not compressed for HAC lag distances. Report asymptotic normal p-values and 95% intervals; these are approximate for persistent lagged-level regressions and sparse events. Export residuals, fitted values, matrix rank, singular values, condition number, VIF and residual lag-1 correlation using adjacent original-grid pairs. Collection applies Benjamini–Hochberg across all successful non-intercept tests in that submission; dependent tests and alternative HAC bandwidths remain exploratory, not confirmatory discoveries.

Full 2005–2026 and fixed 2005–2014 / 2015–2019 / 2020–2026 windows expose stability. A short post-reversal window must not be picked to maximize significance. Low-frequency ownership/policy analyses must count independent releases/events and ultimately use monthly/event inference. Before interpreting persistent levels, run ADF/KPSS with trend/lag sensitivity, inspect structural breaks and verify cointegration for any ECM. A statistically nonzero rho is not alone proof of stable mean reversion. Static levels OLS and causal event claims are outside the initial executable models.

## Follow-up methods and acceptance

After the initial fit: identical-sample nested tests and partial R²; weekly/monthly reaggregation respecting endpoint availability; trailing 756-session beta stability with sufficient n/k; residual autocorrelation/stress diagnostics; contiguous-block bootstrap (20/60-session blocks, recorded seeds) for generated residuals and interactions; dated governance/index/supply events with confound review and lead windows. These are specified follow-ups, not implemented or already run.

Predictive evaluation, if later authorized, uses expanding chronological training, all tuning within training folds, a final untouched calendar holdout, overlap-aware purging, and comparisons against zero change / AR benchmarks. Full-sample explanatory R² is not forecasting evidence. Slow fundamentals use first public release dates and revision vintages, never future accounting period values.

An empirical report is reviewable only with input/code/config hashes, timing/coverage report, exclusions, coefficient uncertainty, unestimated-model reasons, sample definitions, units, and an interpretation against competing mechanisms. Publish no vote value, discount-rate effect or causality from association alone.

## Remaining core-pair price baselines (November 9, 2026)

The SK Square/SK Hynix, Samsung Fire/Samsung Electronics common, and TSMC local/ADR extension is a separate retrospective price-measurement exercise. It does not convert either Korean holder-company pair into a NAV discount. The executable specification is `configs/core_pair_baselines.v1.json`; `scripts/run_core_pair_baselines.py` writes a hash manifest, identifier and fundamentals audits, source-tagged panels, coefficient tables, model status, join coverage, and a report.

For each Compustat Global leg, the exact GVKEY/IID, company name, currency, active security descriptor, ISIN, and dated security-history rows must match the frozen configuration. Duplicate GVKEY/IID/date keys block construction. Compustat closes are divided by `AJEXDI × QUNIT`; CRSP ADR closes are divided by `DlyCumFacPr`. This is a price adjustment for splits and share distributions, not a dividend total-return series. Rows with `PRCSTD != 10`, missing/nonpositive price or factor, or a missing paired endpoint remain unusable; no isolated bad day is hand-repaired, interpolated, or bridged by a change calculation.

The Korean same-currency gaps use `q_t = 100 × (1 − (L_t/R_t)/(L_0/R_0))`, where the first usable adjusted-price ratio is only a scale anchor. Positive q means the left security has underperformed the right security relative to that first date. DEXKOUS is audited but not applied because a same-date KRW/USD conversion cancels from the ratio. These q series are normalized price gaps, not holding-company or look-through NAV discounts.

For TSMC, one ADS represents five Taiwan common shares. The retrospective ADR premium is `q_t = 100 × (ADR_t / (5 × Local_t / DEXTAUS_t) − 1)`, with DEXTAUS in TWD per USD. Taiwan and US closes are not simultaneous. The FRED observation is a noon New York fixing after the Taiwan close, so same-calendar-date FX is not available at the Taiwan close and cannot support a point-in-time trading claim. The panel retains `gap_pct_prior_fx`, using the latest fixing strictly before the Taiwan calendar date, as a transparent timing sensitivity; the frozen B00 baseline uses the conventional same-date retrospective conversion.

TSM ADR rows through September 30, 2026 use CRSP PERMNO 85442. Rows from October 1 through November 6 use Compustat North America GVKEY 201395/IID 90. The five overlapping September closes must match numerically before stitching. Every row carries `adr_source`; CRSP-only return, bid, and ask fields remain missing in the Compustat continuation. Exact duplicate CRSP export rows may be deduplicated, but conflicting duplicate dates block construction.

The baseline regression follows the existing B00 convention: `Δq_t = α + ρ q_(t−1) + ε_t`. Differences and lags are formed on the outer date grid before complete-case selection and never bridge an unusable endpoint. Models use an intercept, Bartlett Newey–West covariance on the original grid, HAC lags 5/20/60, minimum n=252, and the fixed full, 2005–2014, 2015–2019, and 2020–2026 windows. Actual sample endpoints, n, join losses, adjusted R², rank/conditioning, coefficients, standard errors, and p-values are output. Alternative windows and HAC lags are robustness views, not independent discoveries; low in-sample adjusted R² and a negative ρ do not establish fair value, causality, forecast value, or executable convergence.

Annual and quarterly Compustat Global fundamentals are audited separately by entity, period coverage, and presence of vendor `fdate`/`pdate` fields. Those fields do not establish the original public-release clock or revision vintage. Fundamentals and the filing observations are not forward-filled into daily panels. Korean NAV regressions remain pending until each pair has a dated ownership history and point-in-time balance-sheet/valuation inputs; individual filings and commit `3666efa` are observations, not histories.

## Hypothesis-resolution batch (November 9, 2026)

The executable mechanism batch is frozen in `configs/hypothesis_resolution_v1.json`, implemented in `src/samsung_research/hypothesis_resolution.py`, and submitted with `slurm/hypothesis_resolution.sbatch`. The reviewed result is `runs/hypothesis_resolution/15204916/results`; the tracked interpretation is `docs/regressions/HYPOTHESIS_RESOLUTION_RESULTS_20261109.md`.

The annual S06/L01 test uses only joint-eligible annual rows from the reviewed LHB panel. Levels use 17 observations (2005 and 2010–2025); first differences require consecutive observations and use the 15 changes from 2011–2025. HC1 OLS is accompanied by fixed-seed 20,000-draw partial permutation inference and Spearman ranks. The joint level model includes relative non-treasury supply, relative activity, and a centered linear time control. These are small-sample retrospective associations. Non-treasury shares are not public float, and activity per year-end shares is not spread, depth, signed flow, or cost.

The M04/B03 leg decomposition regresses adjusted-price forward common, preferred, and preferred-minus-common log returns on the current percentage-point discount change at fixed 1/5/20-session horizons. Missing or flagged endpoints invalidate the entire interval and are never bridged. Newey–West bandwidth is `max(5,horizon)` on the original observed-session grid. The full sample and fixed 2005–2014, 2015–2019, and 2020–2026 windows are reported. This identifies which observed price leg follows a widening in sample; it does not identify stale quotes, investor type, execution cost, or out-of-sample predictability.

Issuer disclosures use the previously frozen six-row manifest and conservative next-observed-session origins because exact publication clocks are unavailable. Authorization, aggregate execution report, cancellation decision, and dividend decision remain distinct. Connected disclosures are not independent events; cancellations are not second purchases; aggregate executions are never distributed backward over daily rows. Event windows are descriptive case studies only.

TSMC timing regressions use two information states. At the Taiwan close, the parity gap uses the prior ADR close and latest FX fixing strictly before the Taiwan date; the outcome is the later same-date ADR price return. At the US close, the gap uses the same-date Taiwan close and noon-New-York FX; the outcome is the next Taiwan-session local price return. HAC(5) is reported for the full and fixed subperiods. The sensitivity excludes ADR relative spreads above the historical 90th percentile. The design distinguishes venue timing but cannot establish executable arbitrage without simultaneous local quotes, conversion/creation costs, and borrow constraints.

All batch horizons, outcomes, clocks, and sensitivities were frozen before the final run. P-values are exploratory and are not multiplicity-adjusted; horizons overlap and common/preferred/relative outcomes are mechanically related. Conclusions therefore emphasize signs, magnitudes, fixed-subperiod consistency, proxy limitations, and discriminating observations rather than discovery counts.

## LOOP-exception generalization batch (November 9, 2026)

The workbook `docs/project_purpose/LOOP Exceptions - Companies vF.xlsx` defines a broader candidate universe than Samsung. The executable subset is frozen in `configs/loop_exception_tests.v1.json` and run by `scripts/run_loop_exception_tests.py` through `slurm/loop_exception_tests.sbatch`. Licensed annual asset Parquets remain in the shared research database and outside Git. The output stores only aggregate audits and results under Git-ignored `runs/`; it does not copy licensed security rows.

Before panel construction, the batch audits BARRID/date uniqueness; effective names, tickers, instrument types, currencies, and coverage; and missing price, return, volume, bid/ask-spread, and market-cap fields. All selected proxy listings are USD. Exact-date joins are used with no holiday forward-fill. Price and vendor-return disagreement exceeding three percentage points marks a likely adjustment/action boundary; that change row is excluded, while prices are never edited and other large moves remain. Berkshire begins on January 21, 2010, after its Class B 50-for-1 split established the 1,500:1 current economic ratio. BN/BAM begins December 12, 2022, after the new structure rather than in when-issued trading.

Seven locally available US pairs are tested: Alphabet A/C, Berkshire A/B, News B/A, Fox B/A, Liberty Broadband A/C, Petrobras common/preferred ADRs, and Volkswagen common/preferred ADR proxies. The level is `g_t = log(P_left/(units × P_right))`; the descriptive premium is `100 × (exp(g_t) − 1)`. B00 estimates `100Δg_t = α + ρ(100g_(t−1)) + ε_t` with HAC(20). These levels can describe relative prices, but different voting, dividend, tax, depositary, and liquidity rights mean zero is not universally fair value.

Mechanism tests use only declared designs. Leg adjustment reports average left, right, and relative price moves 1/5/20 sessions after a one-percentage-point left-relative widening. The liquidity regression relates the absolute deviation from the prior 252-session median to standardized combined relative quoted spread and absolute log turnover-proxy difference, with HAC(20). Missing quote history blocks the relevant result rather than being filled. The cross-pair test applies PCA to complete-case standardized US differential price changes from 2019 onward and reports exact-calendar correlations to the three core-pair changes; those correlations do not synchronize Asian and US close times.

The walk-forward comparison trains an expanding B00 after at least 252 observations and compares next-change RMSE with zero-change persistence and a prior-252-session median-level forecast. The mechanical trading sensitivity takes the opposite side of a prior-information 252-session z-score when `|z| ≥ 1`, applies the position to the next pair-price change, and charges half the sum of observed relative quoted spreads when the position changes. It is deliberately incomplete: no borrow availability or fees, dividends, taxes, locate constraints, market impact, or depositary/conversion costs are available. Gross or quoted-spread-net statistics therefore are diagnostics, not investable portfolio performance.

Six holdco/heldco proxy pairs are estimated as contemporaneous return pass-through regressions with an interaction for negative heldco returns: Liberty Broadband/Charter, BN/BAM, SoftBank/Arm, Prosus/Tencent, Naspers/Prosus, and Investor AB/Atlas Copco. HAC(20) up- and down-market betas and 252-session rolling betas are reported. No holdco price ratio is called a NAV discount. Exact primary/ADR, A/H, local-class, or NAV tests remain blocked where the shared assets data contain only a US proxy or lack dated structural denominators.

The separately staged Prosus/Tencent local-security sensitivity uses `configs/core_pair_gap_regressions.v1.json` and `scripts/analyze_core_pair_gaps.py`. It converts exact-date Prosus EUR and Tencent HKD closes to USD with observed ECB cross-rates, normalizes the first usable ratio for units only, excludes adjustment/split boundaries rather than repairing them, and aligns the same eleven retrospective USSLOWL factors by preceding US sessions. B01–B04, main/action-window sensitivity variants, HAC(5/20/60), fixed windows, BH q-values, alignment rows, and input hashes are retained. This is deliberately not a NAV model because dated holdings, other assets, liabilities, tax leakage, and share counts are absent.
