## Research discipline

When progress stalls, return to this tree: identify which branch is unresolved, which observation separates it from its nearest rival, whether that observation can actually be obtained, and what small predeclared test would change the decision. Expand real mechanisms and subbranches where distinctions matter. Do not add arbitrary lag/interaction/window combinations to make the tree large. Preserve negative evidence and access failures. Source clock, vintages, units, class mapping, independent event count and confounds are part of each branch, not an afterthought.
