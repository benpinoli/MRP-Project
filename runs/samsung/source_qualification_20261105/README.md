# Scoped KRX and GDR source qualification

Checked 2026-11-05 UTC, no login, credentials, paid products, retries after denial, or bulk scraping. This is access/provenance research; no new forecasting input has been qualified.

The official [KRX marketplace](https://data.krx.co.kr/contents/MDC/MAIN/main/index.cmd?locale=en) homepage returned HTTP 200 and lists Trading by investor (individual issue, MDC0201020302), Foreign ownership by issue (MDC0201020504), Short-selling transaction by issue (MDC02030201), and Short position by issue (MDC02030301). Following the four site's own menu links as an anonymous user returned HTTP 200 with a 407-byte script alert stating login or signup is required, directing to login. Thus HTTP 200 alone does not mean data access. No login or registration was attempted. [API terms](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO005.jsp), articles 3 and 5, require application for an authentication key; article 6 limits API use to noncommercial purposes. The [documented process](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp) requires login, key application and administrator approval. No key was requested. Terms, redistribution and permissible use must be revisited for any authorized later access.

A separately public [short-sale screen](https://data.krx.co.kr/comm/srt/srtLoader/index.cmd?isuCd=002230&screenId=MDCSTAT300) returned HTTP 200 and a query form but no embedded data rows. Its own script specifies `dbms/MDC_OUT/STAT/srt/MDCSTAT30001_OUT`; its loaded `mdc.util.js` sends form fields to `/comm/bldAttendant/getJsonData.cmd` by POST. One documented request for common ISIN KR7005930003, 2026-10-01 through 2026-10-20, returned HTTP 403; no data returned. No retry, cookie/session manipulation, spoofing or preferred-class query followed this denial. Screen labels identify quantities in shares and amounts in KRW; complete historical panel availability for 005930/005935 remains unverified. Its Korean notes state net short positions have coverage from 2016-06-30, reflect reporting at T+2 and can change for new/corrected reporting after 18:00; regular-session transactions appear after 15:40 KST, all-day transactions after 20:10 KST; data combine KRX and NXT from 2025-03-04. These are distinct clocks, not a point-in-time historical revision archive. Foreign ownership is a stock, not signed investor net buying. No assumption about first-release vintages or class coverage is justified.
